Jogo autoral com a temática de um ladrão em busca de roubar o diamante mais caro do MUNDO

---
## 🛠️ Stack
Stack Utilizada:

=>JavaScript
=>HTML
=>p5.js

## 📚 Aprendizados
- Game arte com pixel art
- Conceitos e técnicas em JavaScript
- Aprendizados com a ferramenta p5.js

## ⚙️ Funcionalidades
- Aperte as setas do teclado ou as teclas (W) (A) (S) (D)
- Aperte a tecla R para recomeçar o jogo caso perca
- Não seja atingido pelos lasers
